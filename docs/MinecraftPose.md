# MinecraftPose

This environment is part of the tactile regression environments.
Refer to the [tactile regression environments overview](TactileRegressionEnv.md) for a general description of these environments.

|                              |                  |
|------------------------------|------------------|
| **Environment ID**           | MinecraftPose-v0 |
| **Prediction Dimensions**    | 4                |
| **Step limit**               | 64               |
| **Sensor rotation**          | disabled         |
| **Object pose perturbation** | enabled          |

## Description

In the MinecraftPose environment, the agent's objective is to locate a Minecraft item positioned randomly on a platform and estimate its precise 2D position and 1D orientation.
The objects are generated by extruding the items' 16x16 pixel sprites into flat 3D meshes, the same way Minecraft renders dropped items.
Like Toolbox, MinecraftPose poses a regression problem that requires combining multiple touch observations to resolve ambiguities inherent in the objects' shapes.
However, unlike in Toolbox, where the object is always the same wrench, the object in MinecraftPose is sampled from 301 different items in each episode.
Hence, the agent has to learn exploration strategies that generalize across a large variety of object shapes, some of which are (close to) rotationally symmetric and thus require careful exploration of fine details to disambiguate their orientation.

Since the set of items is fixed, this environment has no train/test split; every instantiation uses all 301 items.

> **Note:** the Minecraft item meshes are generated on the fly from the official Minecraft game assets, which are downloaded directly from Mojang's servers on first use (~30 MB) and cached locally.

## Prediction Target Space

The prediction target is a 4-element `np.ndarray` containing a pose representation of the item.
The first two elements are the 2D coordinates of the item's model frame (located in the center of the item's sprite) in platform coordinates, normalized to the range $[-1, 1]$.
The last two elements are the sine and cosine of the item's rotation around the Z-axis.

## Example Usage

```python
import ap_gym

env = ap_gym.make("MinecraftPose-v0")

# Or for the vectorized version with 4 environments:
envs = ap_gym.make_vec("MinecraftPose-v0", num_envs=4)
```
